# D2D Platform

Работать по-русски. Этот проект отделён от PSModule. Только локальная разработка: пользователь отдельно предоставит сервер и домен для деплоя.

## Проверки
- `npm test` — API, авторизация, изоляция проектов, конкурентные сессии.
- `npm run build` — TypeScript и production-сборка интерфейса.
- `npm start` — приложение на 127.0.0.1:19090; `npm run dev` — режим разработки.

## Правила
- Не добавлять SMTP: регистрация по логину и паролю, восстановление резервным кодом.
- Не показывать запланированные интеграции как работающие.
- Любая запись в проект проверяет членство, роль и при необходимости актуальную рабочую сессию.
- Секреты и рабочие данные в `.d2d` не коммитить.
- Источники права — БД и политика сервера; инструкция агента не заменяет авторизацию.
