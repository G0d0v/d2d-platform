# D2D 0.6.1 — дизайн и удобство загрузки

Дата: 16 ноября 2026.

Методика: [unslop](https://github.com/heydamir/unslop), автор Damir Sokolovsky (@heydamir), CC BY 4.0. Навык установлен по прямому запросу пользователя в `~/.codex/skills/unslop`. Дополнительные зависимости приложения не устанавливались. Использован ранее согласованный объём `SKILL-SCOUT-GITHUB-REDESIGN.md`.

## Направление

- Продукт: приватное пространство совместной разработки закрытой команды.
- Характер: спокойный, точный, рабочий.
- Среда: привычный Git-репозиторий, дерево файлов, история и проверка кода.
- Цветовые акценты: изменения кода и фактические статусы; оформление вокруг них нейтральное.
- Повторяемая деталь: папка и ветка назначения видны до сохранения файлов.

Существующее оформление по референсам GitHub сохранено. Аудит выявил отдельные проблемы, поэтому применён режим доработки, без нового брендинга и перестановки разделов.

| Выбранная строка отличалась только наведением | Отдельное обозначение выбранного файла и клавиатурного фокуса |

## Девять проходов

1. Отступы: общие панели, карточки агентов/серверов, уведомления и формы приведены к одной сетке.
2. Цвет: существующая палитра двух тем сохранена, основное действие выделяет сохранение файлов.
3. Иконки: существующий Lucide; технические пиктограммы рядом с действиями, без декоративных эмодзи.
4. Текст: «Сохранить файлы», «Что изменилось», «Добавить в эту папку»; Git-термины вынесены из основного сценария.
5. Типографика: системный шрифт с кириллицей, подписи от 12px, спокойные заголовки 500–600.
6. Компоновка: папка назначения → выбор → результат → заметка → сохранение; дополнительные настройки раскрываются отдельно.
7. Детали: состояния выбора, подтверждение замен, защищённое закрытие черновика, фиксированная область кнопок в длинной форме.
8. Визуальное содержание: реальные файлы, пути и история; декоративные изображения не добавлялись.
9. Движение: только короткая обратная связь; учтён reduced motion, передача отображается настоящим progress.

## Проверки

- `npm test`: 39 тестов, 38 прошли; интеграционный тест без конфигурации Forgejo пропущен.
- Отдельный запуск `server/git.test.ts` с настоящим Forgejo через SSH-туннель: 3/3 прошли, включая новый API списка путей.
- `npm run build`: TypeScript и production-сборка проходят.
- Браузер: новый и заменяемый файл в `docs`, сохранение соседнего файла, замена файлом с другим локальным именем, папка с вложениями в новой ветке и исключение `.env`.
- Для браузерных проверок использована отдельная БД и временный Git-проект. Существующие проекты пользователей не изменялись.
- Первый полный интеграционный запуск на сервере остановлен OOM; тест успешно перенесён на рабочий компьютер. Нагрузочные тесты на малом рабочем сервере больше не запускались.

Сервер по-прежнему проверяет членство, роль, рабочую сессию и исходный коммит. Предварительный просмотр не заменяет авторизацию. Прерывание связи после отправки требует проверки истории перед повтором.
