# D2D Platform — контракт интерфейса

Русский рабочий инструмент для маленькой команды. Согласованное направление от 14 ноября 2026: максимально близкое к пяти предоставленным скриншотам GitHub оформление, с названием D2D, русскими текстами и действительными возможностями платформы.

Верхняя панель на всю ширину: меню пространства, знак D2D, путь, поиск, тема и профиль. Навигация — горизонтальные вкладки с оранжевым подчёркиванием; меню открывает боковую панель на любом экране. Основной контент центрирован, ширина до 1280px. Список проектов — разделённые линиями записи, рядом профиль пользователя. Репозиторий — панель ветки и действий, плотная таблица файлов, README и правая колонка описания/релизов. Релизы — индекс версий и карточки. Проверка изменений — индекс файлов и панели diff.

Тёмная тема: фон #0d1117, верхняя панель #010409, вторичная поверхность #161b22, граница #30363d, основной текст #e6edf3, ссылки #58a6ff, зелёное основное действие #238636. Светлая тема использует те же смысловые токены. Системный шрифт с кириллицей, основной размер 14px; код 12–13px моноширинный. Радиус 6px, без декоративных градиентов и крупных карточек статистики.

Главное действие проекта: «Взять в разработку». Если занят — карточка владельца и запрос передачи. Открытая вкладка и владение различаются.

Обязательные состояния: загрузка, пусто с действием, ошибка с восстановлением, недостаточные права, потеря связи, успешное сохранение. Отсутствуют фиктивные метрики и демонстрационные проекты в пользовательской базе.

Светлая/тёмная темы, клавиатура, visible focus, reduced motion, мобильная навигация. Сетка 4/8px; компактные кнопки от32px, на сенсорных экранах от40px. На узких экранах колонки складываются, вкладки прокручиваются горизонтально, код прокручивается внутри панели. Длинные имена не расширяют страницу.

Не добавлять фиктивные GitHub-функции и метрики. Запись и установка сохраняют действующие проверки прав и рабочей сессии. README форматируется без исполнения HTML; diff использует реальные данные API. Для каждого экрана проверять загрузку, пустое состояние, ошибку, разрешения и работу с клавиатуры.
