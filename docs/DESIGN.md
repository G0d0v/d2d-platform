# D2D Platform — контракт интерфейса

Русский рабочий инструмент для маленькой команды. Основа из согласованного плана и пользовательских референсов PSModule: графитовые поверхности, широкая навигация с подписями, тонкие границы, спокойные мятные статусы. Типографика системная с кириллицей. Код — моноширинный.

Главное действие проекта: «Взять в разработку». Если занят — карточка владельца и запрос передачи. Открытая вкладка и владение различаются.

Обязательные состояния: загрузка, пусто с действием, ошибка с восстановлением, недостаточные права, потеря связи, успешное сохранение. Отсутствуют фиктивные метрики и демонстрационные проекты в пользовательской базе.

Светлая/тёмная темы, клавиатура, visible focus, reduced motion, мобильная навигация. Сетка 4/8px; кнопки от40px. Акцент только на главном действии; код и таблицы используют доступную ширину.
