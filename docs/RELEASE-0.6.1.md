# D2D Platform 0.6.1 — удобная загрузка и замена файлов

Обновление для повседневной работы закрытой команды разработчиков. Оформление доработано по методике [unslop](https://github.com/heydamir/unslop) (Damir Sokolovsky, CC BY 4.0), с сохранением привычного интерфейса GitHub.

## Файлы и папки

- Видимая кнопка **«Добавить файлы»** и действие **«Добавить в эту папку»** в репозитории.
- Выбор отдельных файлов, целых папок и ZIP, перетаскивание файлов и папок с вложениями.
- Список можно дополнять, искать в нём и убирать отдельные позиции до отправки.
- Перед сохранением видно, сколько файлов добавится и сколько заменится. Для замены требуется подтверждение.
- **«Заменить файл»** сохраняет имя и расположение файла в проекте, даже если локальная новая версия называется иначе.
- Папка и ветка назначения всегда видны. Создание отдельной ветки доступно в дополнительных настройках.
- Настоящий прогресс передачи и отдельный статус сохранения в Git.
- Загрузка папки автоматически исключает `.git`, `.d2d`, `node_modules`, `.env` и приватные ключи, показывая предупреждение. `.env.example` разрешён.
- Описание изменения необязательно: без него D2D составляет понятное сообщение коммита.
- Общая форма выбора используется и для начальной загрузки проекта. Адрес проекта автоматически заполняется по русскому названию.

## Интерфейс

Уточнены отступы и типографика общих панелей, строк файлов, форм, уведомлений, агентов и установленных проектов. Выбранная строка и клавиатурный фокус различимы. Тёмная и светлая темы сохранены; длинная форма работает на узком экране.

Раздел установки объясняет разницу между редактированием кода и готовыми архивами. Из папки архивного просмотра можно перейти к добавлению файлов в соответствующую папку текущей ветки; опубликованный архив при этом сохраняется.

## Обновление сервера

```bash
curl -fsSL https://raw.githubusercontent.com/G0d0v/d2d-platform/main/update.sh | sudo bash
```

Установщик сохраняет резервную копию и использует пакет изменений, когда он доступен для установленной версии. Аккаунты, проекты, конфигурация и данные остаются в своих каталогах. Миграций схемы БД в 0.6.1 нет.

39 локальных тестов: 38 прошли, один пропущен без конфигурации Forgejo. Отдельный запуск с настоящим Forgejo: 3/3 прошли. TypeScript и production-сборка проходят. В браузере проверены добавление, замена, вложенные папки, новая ветка и сохранение соседних файлов.
