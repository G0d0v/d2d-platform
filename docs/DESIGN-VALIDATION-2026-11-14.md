# Проверка редизайна D2D 0.4

Основание: пять скриншотов GitHub от пользователя; Skill Scout согласован ответом «Давай». Новых зависимостей и сервисов нет.

## Изменения

- Верхняя панель, меню пространства на любом экране и горизонтальные вкладки; активный раздел подчёркнут оранжевым.
- Профиль и список проектов, компактные действия загрузки/создания, палитры тёмной и светлой тем.
- Единая навигация репозитория с прямыми ссылками на код, проверки и релизы; история коммитов с постраничным просмотром.
- Панель ветки, таблица файлов, полный текст и копирование кода, безопасное форматирование README, правая колонка проекта.
- Индекс релизов, поиск, карточки с Markdown и существующими действиями подготовки версии к установке.
- Diff: список и фильтр файлов, отдельные панели, номера старых/новых строк, добавления/удаления и UTF-8 пути Git.
- Формы входа, настройки, участники, задачи, исходники и установка используют общие компоненты и темы.

## Автоматическая проверка

`npm test`: 31 пройдено, 1 интеграционный тест настоящего Forgejo пропущен без локальной конфигурации; ошибок нет. Последующие целевые проверки изменённых Markdown/diff: 4/4.
`npm run build`: TypeScript и production-сборка проходят. `git diff --check`: без ошибок пробелов.

Новые тесты проверяют независимые номера строк diff, границы файлов, содержимое с префиксами +++/---, quoted UTF-8 пути Git и экранирование HTML/блокировку исполняемых Markdown-ссылок.

## Браузер

- Локальная production-сборка проверена через CUA с реальными ответами опубликованного D2D в режиме только чтения; данные и права пользователей не менялись.
- Проверены список проектов, открытие репозитория, реальные ветки и README, форма загрузки исходного проекта, поиск на мобильном экране, меню и светлая тема.
- На ширинах 320, 768 и 1024px ширина документа не превышала ширину экрана; при 1440px проверена композиция списка проектов.
- Заполненные карточки релиза и diff проверены на локальном изолированном наборе тестовых ответов. Эти данные не публикуются на сервере и не входят в сборку.
- В проверенном окне diff нет предупреждений и ошибок консоли; русские длинные имена переносятся.

## Границы

Форматирование Markdown поддерживает заголовки, списки, таблицы, цитаты, блоки кода, ссылки HTTP(S) и внутренние якоря. HTML не исполняется. Изображения и относительные ссылки на файлы пока показываются текстом. Полной совместимости с GitHub Flavored Markdown и подсветки синтаксиса всех языков нет.

Релизные архивы подготавливаются действующим API snapshot и доступны в разделе установки. Автоматические сборки на каждый push, звёзды, форки, Actions и другие отсутствующие функции GitHub не имитируются.
