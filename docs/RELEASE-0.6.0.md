# D2D 0.6.0 — загрузка без ZIP и обновления по изменениям

Релиз для закрытых команд программистов: работа с файлами прямо в репозитории, понятное сравнение версий и обновление установленного проекта без повторной передачи всех исходников.

## Новое

- **Файлы и папки без архива.** В открытом каталоге вкладки «Код» появилась кнопка «Загрузить сюда». Можно выбрать несколько файлов, папку или ZIP, проверить пути и написать описание изменений. Одна загрузка создаёт один Git-коммит; история и соседние файлы сохраняются.
- **Выбор ветки для загрузки.** Файлы и ZIP можно записать в существующую ветку или сразу создать отдельную от выбранной версии. Поддерживается и первый коммит в пустом репозитории.
- **Сравнение релизов.** В карточке версии показываются изменения относительно предыдущей: добавления, удаления, список файлов и красно-зелёный diff. Описание нового релиза автоматически дополняется перечнем изменённых файлов.
- **Пакет изменённых файлов.** Между двумя версиями можно скачать отдельный ZIP с изменёнными файлами, списком удалений и контрольными суммами. Для применения есть Python-скрипт с предварительной проверкой и защитой локальных правок.
- **Экономное обновление установки.** Команда установки проекта автоматически скачивает только изменения между сохранёнными архивами версий. Новые исходники готовятся в отдельном каталоге; после проверки выполняется сборка и запуск. Первая установка и недоступное архивное основание используют полный архив. Различия CRLF/LF учитываются, старым ZIP-установкам Git SHA не нужен.
- **Постоянная команда обновления D2D.** Внизу страницы всегда видны команда, кнопка копирования и ссылка на релизы. Новый `update.sh` создаёт резервную копию и обновляет стандартную Docker- или системную установку платформы. При наличии пакета для установленной версии скачиваются только изменённые исходники; для 0.5.0 → 0.6.0 такой пакет опубликован отдельно.

## Защита данных

Запись проверяет роль, членство, исполнителя и поколение рабочей сессии перед приёмом данных и перед коммитом. Изменение ветки не позволяет перезаписать чужой коммит. Пути вне проекта, `.git`, секреты и символические ссылки отклоняются. Размер исходников не ограничен прежними 25 МиБ: передача идёт потоком на диск. До 10 000 файлов за загрузку.

Пакет обновления сверяет исходные файлы по SHA-256, проверяет новые файлы и не затирает локальные правки. Перед автоматическим обновлением самой платформы сохраняются БД, данные Git и конфигурация. Секреты остаются на сервере.

## Как пользоваться

1. Взять проект в разработку → «Код» → открыть папку → «Загрузить сюда».
2. Выбрать файлы/папку/ZIP → ветку → описание → сохранить коммит.
3. Опубликовать релиз → проверить diff относительно предыдущего.
4. Во вкладке «Установка» выбрать подготовленную версию и получить команду для своего сервера либо скачать пакет изменений из карточки релиза.

Подробности и API: [FILE-UPDATES.md](FILE-UPDATES.md).

```bash
curl -fsSL https://raw.githubusercontent.com/G0d0v/d2d-platform/main/install.sh | sudo bash
```

## Обновление установленной платформы

```bash
curl -fsSL https://raw.githubusercontent.com/G0d0v/d2d-platform/main/update.sh | sudo bash
```

## Отдельные файлы в релизе

Кроме полного архива исходников опубликованы `install.sh`, `update.sh`, `project-installer.sh`, `apply-project-update.py`, `git-delta.py`, пакет `d2d-platform-v0.5.0-to-v0.6.0.zip`, русская инструкция и это описание релиза. Для целой платформы используйте полный дистрибутив; отдельные скрипты предназначены для описанных в инструкции сценариев.

## Совместимость и ограничения

- Node.js 22.12+, Git; для формирования пакетов на сервере D2D нужен Python 3. Docker-образ уже содержит его. Установщику приложения нужен Python 3.10+.
- Новых миграций БД нет; существующие проекты, токены и установки сохраняются.
- Для экономного обновления старой установки нужен сохранённый manifest и исходный архив в D2D. Удаления выполняются только из пакета изменений; загрузка папки сама по себе не удаляет отсутствующие в ней файлы.
- Пакет передаёт целые изменённые файлы, включая двоичные; это не побайтовое сжатие различий. Зависимости и Docker-образы могут загружаться отдельно.
- Автоматическое экономное скачивание работает в команде установки проекта. Панель управляемых серверов пока использует полные архивы.
- Обновление кода не откатывает миграции и данные самого приложения. Для ручного применения пакета при риске отключения питания используйте отдельную копию исходников.
