# Проверки локальной альфы

Проверено 14 ноября 2026 года на Windows, Node.js 24.22.1. Рабочая база отделена от тестов.

## Автоматические проверки

`npm run verify` выполняет TypeScript, тесты API/БД/CLI и production-сборку. Тесты используют настоящий PGlite, без подмены SQL-запросов. Дисковый тест закрывает и повторно открывает базу. CLI-тест запускает отдельные процессы и обращается к HTTP-серверу.

| Гарантия | Проверка |
|---|---|
| Одна активная сессия | 50 конкурентных попыток, один успех и 49 конфликтов |
| Безопасный повтор | Один ключ и одинаковое тело возвращают ту же сессию; другое тело даёт конфликт |
| Передача | Новая сессия с увеличенным поколением; старые исполнитель, URL сессии и поколение отклоняются |
| Срок и связь | Heartbeat не продлевает владение; отсутствие связи не освобождает проект; истёкшая сессия не пишет |
| Роли и изоляция | Наблюдатель не пишет; чужой проект и задача не раскрываются |
| Отзыв полномочий | Отозванный агент не читает и не пишет; сохранённый идемпотентный ответ не раскрывается после потери членства |
| Версия задачи | Предыдущая версия отклоняется после сохранения новой |
| Восстановление | Резервный код меняется, старые cookie и код перестают работать |
| Перезапуск | Сохраняются сессия, аудит и результат ключа; повтор не создаёт вторую запись |
| Выдача интерфейса | JS, созданный после старта сервера, отдаётся как JS; отсутствующий asset не подменяется HTML |

Во время самопроверки временно удалена проверка поколения из `ownedWork`: тест передачи завершился ошибкой. Исходник восстановлен. Эта проверка подтверждает, что тест замечает потерю ограничения.

Аудит npm после обновления `@fastify/swagger-ui` до 6.1.4 сообщил 0 известных уязвимостей. Это результат базы advisories npm на дату проверки, не полный аудит безопасности.

## Проверки в браузере

Использован отдельный учебный экземпляр на `127.0.0.1:19092` с базой в памяти. Проверены вход, список проектов, начало сессии, смена статуса задачи и передача коллеге. После передачи статусы недоступны прежнему исполнителю. Проверены предупреждение о несохранённой форме, тёмная и светлая темы, мобильная навигация. На ширине 390 px список проектов не создаёт горизонтального переполнения документа.

Браузерная проверка обнаружила и позволила исправить ошибку начального пустого состояния и выдачи новых assets после пересборки. Она не заменяет сохранённый воспроизводимый browser E2E: отдельный браузерный пакет не устанавливался.

## Непроверенные условия приёмки

Не запускались настоящий Forgejo, отдельный PostgreSQL, Git push, PR, runner и deployment-agent. Гонки push/передача, смерть процесса между обновлением refs и записью БД, изоляция сборок и восстановление деплоя не подтверждены. Эти операции выключены в интерфейсе и API. Приёмка этапа 1 плана LunaForge остаётся открытой.

Поддержка PostgreSQL предусмотрена адаптером `DATABASE_URL`. Для конкурентных проверок на отдельном сервере БД задайте `TEST_DATABASE_URL` на пустую выделенную тестовую базу и выполните `npm test`. Рабочую БД для тестов использовать нельзя.
